\section{Correction: both previously surviving global pencils are strictly outer}
\label{sec:current-global-candidate-correction}

This section supersedes the unresolved reverse-inclusion status attached to
the order-$8368$ and order-$10736$ candidates in the earlier extraction
release.  It changes no earlier file.  Both matrices remain valid,
explicit outer approximations, but neither is an exact lift of
$\mathcal Q_{222}$.  The proof uses recovered rational certificate data
and checks their agreement with the current matrices; it does not import
a conclusion from an archive title or a historical status field.

\subsection{Closedness and the original eight-coordinate conclusion}

Each $R_i$ is closed.  To see this without assuming closedness of a
general spectrahedral projection, evaluate its features at
$u,v\in\{1,2\}$ and at the four coordinate state vectors.  For
each block the weighted finite evaluation moment is positive definite;
the checker supplies exact positive LDL pivots for all eight moments.
If the source coefficients converge, the sum of those sixteen parent
evaluations stays bounded and equals
\[
                    \sum_b\operatorname{tr}(Q_bM_b).              \tag{RG18}
\]
Since $M_b\succ0$ and $Q_b\succeq0$, all Gram matrices are bounded.
Their limits retain every affine coefficient identity.  The actual
affine Gram range is a closed finite-dimensional linear subspace,
so those limiting matrices still have auxiliary preimages.  Source
nonnegativity is closed as well.

In the two exact closed-face lifts, the Gram diagonals are fixed
linear functions of the source; bounded source coefficients bound
every PSD entry and hence all auxiliary variables.  These coefficient
cones are closed too.  Every transported source has affine constant
$d+\sum c_e$, and Bell relabelings fix that constant.  A convergent
sequence in either finite source sum therefore bounds the nonnegative
mass of each summand.  Passing to a subsequence in each of finitely
many closed source cones proves that $K_N$ is closed.

Separate the point $f_*$ from this closed cone.  There is a nonzero
$x\in K_N^*$ with $f_*\cdot x<0$.  The 16 event inequalities belong
to $K_N$.  Their sum at each input is $4x_0$, so $x_0\geq0$.
If $x_0=0$, all event evaluations vanish; their linear span is the
full affine coefficient space, forcing $x=0$.  Hence $x_0>0$, and
$x/x_0=(1,q)$ for an original eight-coordinate behavior.  By (RG2),
$q\in\mathcal O_N$, while $f_*(q)<0$ implies $q\notin\mathcal Q_{222}$.
Together with the soundness inclusion, this proves
\[
 \boxed{\mathcal Q_{222}\subsetneq\mathcal O_{8368},\qquad
        \mathcal Q_{222}\subsetneq\mathcal O_{10736}.}             \tag{RG19}
\]
This is a strictness theorem, not an evaluated nonquantum point with
all thousands of auxiliary coordinates printed.
