# Recovery limits and version distinctions

The publication includes the available mathematical material in the recovered source roots, scientific analysis folders and current repository, together with additional original files fetched from the completed project chats on 26 October. The source map records the precise scope and every included file. This is not a claim that every artifact ever mentioned in the online project has been recovered.

| Item | Material available now | Remaining limit |
|---|---|---|
| Full R21 release | Original 65 MB archive, 798-page recovered volume, 215 original components, 215 presentation copies, indexes and dependency bindings | This is distinct from the previously mentioned 549-page/226-component release, which remains unrecovered |
| Earlier nested R21 continuation archive | Preserved byte-for-byte inside the original release | One inherited ZIP lacks a readable central directory. Its recoverable local entries were inspected, but it is not represented as a separately verified usable ZIP. The outer release and all indexed proof/dependency bodies are checked separately |
| R2 coefficient proof | Original complete ZIP, six-checker package, proof and recorded verification log fetched | New local replay and integrated mathematical reconciliation remain separate tasks |
| R3/R4 and R6/R7 independent review | Original complete ZIP, all packaged modules and recorded replay log fetched | The newly fetched modules have not been rerun in this delivery pass |
| IC/LII original proposal | Original full proof and complete checker package fetched | The later independent follow-up chat and its claimed correction remain unavailable; no correction has been invented or silently incorporated |
| BN/UN | Original proposal, corrected independent proof, both complete checker packages fetched | Use the corrected normalization; reconcile the integrated manuscript before a new global verification claim |
| EL/NU | Complete independent proof and eight exact modules already published on main | Earlier failed tiny previews are superseded and excluded from the delivered proof corpus |
| External R1 multi-part extraction | The independent order-283 construction and its full data are public | The separate interrupted external multi-part extraction is not counted as recovered |
| Finite-c continuation | Existing endpoint proofs, candidate matrices and recorded calculations are public | An unfinished online run is not counted as a completed proof or artifact |

Rendered proof recoveries are labeled by their filenames. Original file-card and package downloads are retained separately with their recovery receipt. Historical proof packages may contain paths specific to their original environment; the original archives preserve those dependencies and the current repository supplies the maintained constructions.

Browser screenshots, unrelated sidebar content, complete raw UI dumps, local credentials, runtime caches and vendored dependencies are not copied into the new loose-file publication. Original supplied research archives are preserved without rewriting their contents. Exact-byte duplicates already present in the repository are mapped to their existing public paths.
